## Структура проекта

```text
lab5_var10/
├── core/                 # логика без привязки к GUI, её проверяют тесты
│   ├── chat.py           # сообщения, история, TCP-сервер и клиент
│   ├── clicker.py        # правила игры «Кликер»
│   ├── file_utils.py     # чтение файла и предпросмотр
│   └── text_utils.py     # преобразование и статистика текста
├── tasks/                # графические приложения
│   ├── clicker_game.py
│   ├── file_dialog.py
│   ├── local_chat.py
│   ├── pyqt_hello.py
│   └── text_button.py
├── main.py               # лаунчер для запуска заданий
├── requirements.txt
└── test_*.py             # unit-тесты
```

Логика вынесена в отдельный пакет `core`, поэтому её можно проверять без
запуска окон. Графический слой (`tasks`) только вызывает эти функции.

## Установка

```bash
pip install -r requirements.txt
```

`tkinter` входит в стандартную поставку Python. Для задания на PyQt5 нужен
пакет `PyQt5` из `requirements.txt`.

## Запуск

Общее меню:

```bash
python main.py
```

Откроется окно-лаунчер, из которого каждое задание запускается отдельным
процессом. Если окно недоступно, есть текстовое меню:

```bash
python main.py --cli
```

Отдельные задания:

```bash
python -m tasks.pyqt_hello
python -m tasks.text_button
python -m tasks.file_dialog
python -m tasks.local_chat
python -m tasks.clicker_game
```

## Как проверить локальный чат

1. В первом окне нажать **«Запустить сервер»**, затем **«Подключиться»**.
2. Запустить приложение ещё раз (`python main.py`) и во втором окне нажать
   **«Подключиться»** — сервер уже работает в первом окне.
3. Писать сообщения: они появляются в обоих окнах.

Сервер слушает `127.0.0.1:8765` и отправляет каждое сообщение всем
подключённым клиентам. Новому клиенту сразу передаётся история переписки.

## Тесты

```bash
python -m unittest discover -v
```

Тесты покрывают преобразование текста, чтение файла, правила игры «Кликер»,
а также сериализацию сообщений и реальную доставку сообщения между двумя
клиентами через локальный сервер.

## Кратко о реализации

- **PyQt5 (средн. 10).** Окно `QWidget` с меткой и кнопкой; кнопка меняет
  текст и считает нажатия.
- **Текст и кнопка (средн. 2).** Ввод строки, выбор режима (регистр, реверс,
  title) и вывод результата вместе со статистикой по тексту.
- **Диалог файла (средн. 8).** Выбор файла через `filedialog`, предпросмотр
  первых 1500 символов, размер файла и число строк.
- **Локальный чат (повыш. 10).** Настоящий обмен по TCP: сервер в фоновом
  потоке, клиент принимает сообщения в отдельном потоке, интерфейс получает
  их через очередь.
- **Кликер (повыш. 3).** Раунд длиной 10 секунд: счёт, клики в секунду и
  рекорд.
